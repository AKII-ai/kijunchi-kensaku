# 主要基準一覧の行

値は書かない。物質の並びと、各列の出典でその物質がどう呼ばれているかだけを書く。列の定義は [columns.md](columns.md)。

- `## 見出し` が分類。その中の表の1行が1物質で、上からこの順で出す。
- セルには、その列の出典の表に出てくる呼び方を書く（条文・告示の表記のまま。全角・半角も合わせる）。
  比べるときは空白、かっこ書き、〈ルビ〉、頭の号番号を無視する（`src/summary/summary.js` の itemKey）。
- 空欄は「その出典にこの物質の項目が無い」。規制が無いという意味ではない。
- 列の出典と別の出典から取るときは `出典名: 呼び方` と書く（ダイオキシン類の環境基準など）。
- 「注記」は、その行だけの根拠や読み方。物質名に「注n」を付け、表の下の「根拠と注」に出す。URL を書いてよい。
  列の出典と別の出典から取ったセル（`出典名: 呼び方`）があれば、その出典の URL は自動で足される。
- 書いた呼び方が出典に見つからないときは、画面と一覧に「出典に見つからない」と出す。黙って空欄にしない。
