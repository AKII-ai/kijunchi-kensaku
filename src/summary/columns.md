# 主要基準一覧の列

値は書かない。列の名前・単位と、どの出典のどの表から値を取るかだけを指定する。
左からこの順で出す。物質の行は [rows.md](rows.md)。

- 出典が法令IDのときは e-Gov 法令API の現行版から取る。「表」は抜き出しの表の名前（別表第一、本則など）。
- 出典が名前のときは `sources/read/{名前}.json`（保存したページの読み取り結果）から取る。
  「、」で複数書いたときは、左の出典に項目があればそれを使い、無ければ右を見る。
- 単位は、セルの値の単位がこれと同じときに数値だけを出すためのもの。違う単位はセルにかっこ書きで書く。
- 「表」に `別表第二=生活環境項目` のように書くと、その表から取った値の頭に語を付ける。
- 「注記」は、その列の基準の適用範囲など。列見出しに「注n」を付け、表の下に出す。
- 列の出典に無い物質を、別の出典（要監視項目など）で補うときは、rows.md のセルに `出典名: 呼び方` と書き、
  その出典を下の「補う出典」に書く。補った値の頭には「頭に付ける語」が付く。

## 補う出典

列の本来の出典に項目が無い物質を、ここに書いた出典で補う。補った値の頭に「頭に付ける語」を付け、表の下に意味を出す。
同じ語を複数の出典で使ってよい。新しい種類（たとえば要検討項目）を足すときは、出典を `sources/notes/` に整理してから1行足す。

| 出典 | 頭に付ける語 | 意味 |
|---|---|---|
| 要監視項目（公共用水域） | 要監視 | 環境基準ではなく、要監視項目の指針値（令和7年6月30日の通知の別表1） |
| 要監視項目（地下水） | 要監視 | 環境基準ではなく、要監視項目の指針値（令和7年6月30日の通知の別表1） |
| 水質管理目標設定項目 | 目標 | 水質基準ではなく、水質管理目標設定項目の目標値（農薬類は総農薬方式で使う物質ごとの目標値） |
| 水質管理目標設定項目（農薬類） | 目標 | 水質基準ではなく、水質管理目標設定項目の目標値（農薬類は総農薬方式で使う物質ごとの目標値） |
