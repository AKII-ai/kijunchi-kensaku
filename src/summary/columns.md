# 主要基準一覧の列

値は書かない。列の名前・単位と、どの出典のどの表から値を取るかだけを指定する。
左からこの順で出す。物質の行は [rows.md](rows.md)。

- 出典が法令IDのときは e-Gov 法令API の現行版から取る。「表」は抜き出しの表の名前（別表第一、本則など）。
- 出典が名前のときは `sources/read/{名前}.json`（保存したページの読み取り結果）から取る。
  「、」で複数書いたときは、左の出典に項目があればそれを使い、無ければ右を見る。
- 単位は、セルの値の単位がこれと同じときに数値だけを出すためのもの。違う単位はセルに書く。
