# （出典の名前）

URL を開いて保存したあとに書く。基準値の数値は書かない。正本は保存したファイル。
このファイルを sources/notes/{名前}.md としてコピーして使う。足し方は docs/出典を足す.md。

- 名前: （ファイル名と同じ。sources/urls.md の名前とも同じ）
- URL: （読むファイルの URL。本文ページから PDF にリンクしているときは PDF の URL）
- 入手日: （今の保存ファイルを取った日。中身が違ったときだけ書き換える）
- 前回確認日: （URL を開けた日。開けないときは書き換えない）
- 種類: HTML の表 / PDF の別表 / 通知PDF
- 保存したファイル: `sources/saved/{名前}_{入手日}.html`（1つ目を読む。2つ目以降は控え）
- 読み方: （アプリにつなぐときだけ書く。html-table / pdf-table / amendment。tools/sources.py の READERS にある名前）

## どこを読むか

表があるとき

- 使う表: （n番目）
- 項目名の列: （n列目）
- 基準の文言の列: （n列目）
- 測定方法の列: 使わない
- 備考: 基準のセルに混ぜない

表が無いとき（通知PDFなど）

- 値が出てくる見出し:
- 項目名の書き方:
- 基準の文言の書き方:
- 測定方法: 使わない
- 備考: 基準の文言に混ぜない

使わない表があれば、名前と理由を1行書く。
