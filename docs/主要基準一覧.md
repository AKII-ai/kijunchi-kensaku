- 注2 地下水環境基準: 地下水の水質汚濁に係る環境基準について（平成9年環境庁告示第10号）別表。年間平均値（全シアンは最高値） https://www.env.go.jp/content/000344565.pdf（2026-10-04 入手）
- 注3 水質環境基準: 水質汚濁に係る環境基準について（昭和46年環境庁告示第59号）別表1。公共用水域の、人の健康の保護に関する基準。生活環境の保全（別表2）は含めない https://www.env.go.jp/content/000344419.pdf（2026-10-04 入手）
- 注4 水道水質基準: 水質基準に関する省令 表。水道水が満たすべき水質基準 https://laws.e-gov.go.jp/law/415M60000100101（2026-04-01 施行の現行版）
- 注5 排水基準: 排水基準を定める省令 別表第一（有害物質）・別表第二（生活環境項目）。一律排水基準（都道府県の上乗せ基準は含めない）。別表第二の値は頭に「生活環境項目」 https://laws.e-gov.go.jp/law/346M50000002035（2025-07-01 施行の現行版）
- 注6 地下浸透: 水質汚濁防止法施行規則第六条の二の規定に基づく検定方法（平成元年環境庁告示第39号）別表の備考欄。特定地下浸透水に「検出される」とされる値。環境省掲載の全文は平成24年改正までのため、令和6年改正（六価クロム化合物）は改正の概要で上書き（その間の改正の有無は官報で未確認） https://www.env.go.jp/content/000194628.pdf（2026-10-04 入手） https://www.env.go.jp/hourei/add/e025.pdf（2026-10-04 入手）
- 注7 土壌溶出量基準・土壌含有量基準・第二溶出量基準・地下水基準: 土壌汚染対策法施行規則 別表第四（土壌溶出量）・別表第五（土壌含有量）・別表第三（第二溶出量）・別表第二（地下水基準）。土壌汚染対策法の基準。地下水基準は環境基準とは別 https://laws.e-gov.go.jp/law/414M60001000029（2026-07-01 施行の現行版）
- 注8 廃棄物埋立判定基準: 金属等を含む産業廃棄物に係る判定基準を定める省令 別表第一。汚泥等を埋立処分するときの判定基準（溶出試験は環告13号） https://laws.e-gov.go.jp/law/348M50000002005（2017-10-01 施行の現行版）

- 注13 PFOS及びPFOA（合計値）: PFOS と PFOA の合計値。要監視は通知の別表の注「PFOS 及びPFOA の合計値とする」による。水道は省令の表に合計と書かれておらず、合算であることは環境省「水質基準に関する省令改正の概要について」（令和7年8月8日）による https://www.env.go.jp/content/000334172.pdf（2026-10-04 入手）
- 要監視: 環境基準ではなく、要監視項目の指針値（令和7年6月30日の通知の別表1） https://www.env.go.jp/content/000361287.pdf（2026-10-04 入手）
- 目標: 水質基準ではなく、水質管理目標設定項目の目標値（農薬類は総農薬方式で使う物質ごとの目標値） https://www.env.go.jp/content/000378236.pdf（2026-10-04 入手）

## ※ 条件付きの基準（文言のまま）

2. カドミウム及びその化合物／土壌環境基準: 検液１Ｌにつき0.003mg以下であり、かつ、農用地においては、米１kgにつき0.4㎎以下であること
3. 水銀及びその化合物／土壌溶出量基準: 検液一リットルにつき水銀〇・〇〇〇五ミリグラム以下であり、かつ、検液中にアルキル水銀が検出されないこと
4. 水銀及びその化合物／第二溶出量基準: 検液一リットルにつき水銀〇・〇〇五ミリグラム以下であり、かつ、検液中にアルキル水銀が検出されないこと
5. 水銀及びその化合物／地下水基準: 一リットルにつき水銀〇・〇〇〇五ミリグラム以下であり、かつ、アルキル水銀が検出されないこと
6. 砒素及びその化合物／土壌環境基準: 検液１Ｌにつき0.01mg以下であり、かつ、農用地（田に限る。）においては、土壌１kgにつき15mg未満であること
7. アンモニア、アンモニウム化合物、亜硝酸化合物及び硝酸化合物／排水基準: 一リットルにつきアンモニア性窒素に〇・四を乗じたもの、亜硝酸性窒素及び硝酸性窒素の合計量一〇〇ミリグラム
8. アンモニア、アンモニウム化合物、亜硝酸化合物及び硝酸化合物／地下浸透: アンモニア又はアンモニウム化合物にあっては一リットルにつきアンモニア性窒素〇・七ミリグラム、亜硝酸化合物にあっては一リットルにつき亜硝酸性窒素〇・二ミリグラム、硝酸化合物にあっては一リットルにつき硝酸性窒素〇・二ミリグラム
9. 銅／土壌環境基準: 農用地（田に限る。）において、土壌１kgにつき125mg未満であること

## 表の見方

- 数値だけのセルは、列見出しの単位で「以下」。単位が違う値はかっこ書き、「未満」などはセルに書く。
- ―は、その出典にその物質の項目が無いこと（規制が無いという意味ではない）。
- 同じ項目で条件の違う値は、条件を添えて並べる（例: 海域以外／海域）。
- 「要監視」「目標」が頭に付いた値は、その列の本来の基準ではなく、上の「根拠と注」に書いた指針値・目標値。
- 「改正」「更新」は、直近2年に施行された法令の改正、または保存した告示・通知の更新で値が変わったセル（かっこは前の値）。「URL変更」は参照先の URL が移ったもの（新しい URL にしてある）。
- 「参照不可」は、最後に確かめたとき参照先の URL を開けなかったもの（列見出しにあればその列すべて）。値は前回保存したページのもの。
- 載せていないもの: 要監視項目・水質管理目標設定項目のうちこの表に行の無い物質、水道の要検討項目（現行の一覧を公式資料で確かめられていない）、都道府県の上乗せ基準。
