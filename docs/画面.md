# 画面

画面のつくりと、色・ボタンの意味です。見た目は `src/ui/style.css`、動きは `src/ui/app.js` です。

## 並び

- 上の帯は「基準値検索ver1.0」と「出典: e-Gov 法令API・環境省（告示）」。「基準値検索ver1.0」を押すと最初の画面に戻る。見出しも「基準値検索ver1.0」。
- 検索欄。例のボタンは「大気」「土壌」「地下水」。近い法令が無いときはその旨を出す（告示は API に無いので検索結果に出ない）。
- 最初の画面は、上から主要基準一覧、「よく使うもの」。「よく使うもの」は検索対象を狭めるものではなく入口。
- 検索結果や法令の表を出しているときは、画面の上に移動のバーを固定する。
  - 検索結果: 「← 主要基準一覧に戻る」
  - 法令の表（検索から開いたとき）: 「← 法令一覧に戻る」と「主要基準一覧」
  - 法令の表（それ以外から開いたとき）: 「← 主要基準一覧に戻る」

## 法令カード

1法令が1枚。法令名、種別、法令ID。抜き出しで行が1件以上取れたカードは緑。法令を1件選んだら、ほかのカードは消す。

## 法令ごとの表

- 施行期間ごとに表を分け、新しい期間を上に置く。
- `src/layouts/{法令ID}.md` がある法令は物質×列の横並び、無い法令は抜いた順の縦の表（表または条、項目、条件、基準値）。
- 行が1件も取れないときはその旨を出す。空の表は作らない。
- 1つ前の収録版と項目または基準の文言が違うセルは薄い黄色。変更前は同じセルに赤いかっこで書く（欄外には書かない）。
  横並びでは、変わった行の分類と物質名も黄色。廃止された行は打ち消し線。
- 列の境目をドラッグすると、その列の幅が変わる。

## 主要基準一覧

- 見出しの行と物質名の列は、スクロールしても固定。
- 見出しの右端をドラッグすると列の幅が変わる。ダブルクリックでその列だけ元の幅、「列幅を戻す」で全部戻す。幅はそのブラウザにだけ覚える。
- ※ は条件付きの基準。文言は表の下。セルにカーソルを合わせると、値を取った出典の項目名が出る。
- 出典の確認結果のうち「更新あり」「開けない」、法令の取得の失敗、出典に見つからない組合せは、表の上に出す（失敗は赤字）。

## ダウンロード（zip）

作り方は `src/export/` です。

| 対象 | 中身 |
|---|---|
| 開いた法令 | Excel 1冊（施行期間ごとのシート。新しい期間が左）と、施行期間ごとの Markdown（`markdown/01_施行…_現行.md` から古い順）。「変更コメントあり」は上の色と打ち消し線を付け（Markdown は太字・かっこ・打ち消し線）、「コメントなし」は印を付けず、その期間に無くなった行も入れない |
| 主要基準一覧 | Excel（一覧と「注記と出典」の2シート）と Markdown 1つ（`npm run summary` と同じ書き方） |

## 窓・端末

本文幅はウィンドウに合わせて広がる。幅 720px 以下では文字と余白を小さくし、ページ全体が横にはみ出さないようにする。
タッチ画面では、列幅のつまみを太くし、ホバー前提の案内は出さない。
