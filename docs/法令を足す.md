# 法令を足す

法律・政令・府省令は、e-Gov 法令API v2（`https://laws.e-gov.go.jp/api/2`）だけから取ります。ログインは不要です。
告示・条例・通知は API にありません。そちらは [出典を足す.md](出典を足す.md) です。

どの法令でも、検索して開けば表になります。下の3つは「目立たせる・きれいに並べる・取りこぼしを減らす」ための足し方です。

## 1. 「よく使うもの」に出す

`src/ui/featured.js` の `FEATURED` に1行足します。グループを増やすときは `{ name, laws: [...] }` を1つ足します。

```js
{ law_id: "（検索で確かめたID）", title: "（法令名）", type_label: "法律 / 政令 / 省令" },
```

法令IDは、画面の検索か API の `laws?law_title=…&response_format=json` で確かめます。推測して書きません。

## 2. 横並び（物質×基準）の表にする

[templates/layout.md](../templates/layout.md) を `src/layouts/{法令ID}.md` としてコピーし、中身を埋めます。置くだけで読み込まれます（プログラムは直しません）。
見本は `src/layouts/414M60001000029.md`（土壌汚染対策法施行規則）です。

- ファイル名の法令IDと、本文の `- 法令ID:` の行を同じにします。
- 見出しは次の3種類だけです。表の区切り行（`|---|`）は読み飛ばします。値は書きません。

| 見出し | 中身 |
|---|---|
| `## 列` | 画面の列の名前と単位。左からこの順で出す |
| `## 別表` | どの別表をどの列に使うか。「から」が空の行は最も古い版に使い、施行日が「から」以上ならその行を使う。同じ列に新しい「から」があれば新しい行が勝つ |
| それ以外の `## 見出し` | 分類の名前。中の表は「項目」の列だけで、上からこの順で行にする |

- 別表の番号が改正でずれても、列名は意味の名前のままにします（土壌汚染対策法施行規則は 2019-04-01 で番号がずれます）。
- 書いた別表だけを横並びに使います。措置の手順など、基準値でない別表は書きません。
- 項目名は条文の呼び方に合わせます。別名の辞書は持ちません。
- ある版で項目の構成が指定と違うときは、その版だけ API が返した順で出し、表の下にその旨を書きます。

## 3. 抜き出しの取りこぼしを減らす

条文からの抜き出しは `src/extract/extract.js` の4種類です。法令ごとの専用プログラムは作りません。

| 読み方 | 対象 |
|---|---|
| 別表 | `AppdxTable`。行の最後のセルが基準の文言、その手前が項目名 |
| 号列記 | `Item` の `Column`。条の本文に `src/extract/unit_hints.txt` の語がある条だけ |
| 条文の中の表 | `AppdxTable` の外側にある `Table`。見出しだけの行は捨てる |
| 地の文 | 「検出されること」「検出されないこと」で基準を定めている条。1条につき1行 |

号列記で取りたい言い回し（単位の書き方など）が取れないときは、`src/extract/unit_hints.txt` に1行1語で足します。`#` の行は読み飛ばします。
条文の数値の書き方（「一リットルにつき…ミリグラム」など）が読めないときは、`src/extract/value.js` の `WORD_UNITS`・`SYMBOL_UNITS`・`PER_UNITS` に1行足します。

## 主要基準一覧にも出すとき

列として足すときは [主要基準一覧を変える.md](主要基準一覧を変える.md) です。
