# 決まりごとと足し方

このアプリを直す・広げるときに読むところです。起動のしかたとできることは、アプリ直下の [README.md](../README.md) です。

| やりたいこと | 読むところ | 足すもの |
|---|---|---|
| 法令を「よく使うもの」に出す・横並びの表にする・抜き出しの言い回しを増やす | [法令を足す.md](法令を足す.md) | `src/ui/featured.js` に1行、`src/layouts/{法令ID}.md` を1枚、`src/extract/unit_hints.txt` に1行 |
| API に無い出典（告示・通知）を足す・更新を確かめる | [出典を足す.md](出典を足す.md) | `sources/urls.md` に1行、`sources/notes/{名前}.md` を1枚 |
| 主要基準一覧に列・物質を足す | [主要基準一覧を変える.md](主要基準一覧を変える.md) | `src/summary/columns.md` に1行、`src/summary/rows.md` に1行 |
| 画面の色・ボタン・ダウンロードの意味を知る | [画面.md](画面.md) | — |

コピーして使うひな形は [../templates/](../templates/) にあります。
[主要基準一覧.md](主要基準一覧.md) は `npm run summary` が作る表で、手で直しません。

## 守ること

- **値の正本**は、法令はそのとき e-Gov 法令API が返した条文、API に無い出典は `sources/saved/` に保存したページです。
- **数値を Markdown に書かない。** 並びファイル（`src/layouts/`）、主要基準一覧の指定（`src/summary/columns.md`・`rows.md`）、
  URL 台帳（`sources/urls.md`）、整理メモ（`sources/notes/`）には、基準値の数値を書きません。数値は毎回、正本から読みます。
  例外は、正本から機械で作る `docs/主要基準一覧.md`、`sources/read/*.json`、ダウンロードのファイルです。どれも手で直しません。
- **法令IDは推測しない。** e-Gov 法令API の `laws` で検索し、`law_info.law_id` を確かめてから書きます。
- **黙って空欄にしない。** 取れなかった・見つからなかったときは、画面と一覧にその旨を出します（「取得できず」「出典に見つからない」「開けない」）。
- **条文の文言を正とする。** 数値と単位は表に出しやすくするための写しです。「検出されないこと」や「かつ」を含む文は短い数値に置き換えず、
  条件付きの基準は ※ で文言を残します。
- 過去に遡れるのは API が返す版までです（多くの法令でおおむね 2017 年以降）。それより古い基準は官報など原典に当たります。

## 動作の確かめ方

直したあとは、少なくとも次を確かめます。

1. `npm run dev` で開き、主要基準一覧に「取得できず」「出典に見つからない」が出ないこと。
2. 土壌汚染対策法施行規則（`414M60001000029`）を開くと、物質×4列の横並びになること。
3. 水質基準に関する省令を開くと、条文の中の表から行が取れ、二重にならないこと。
4. 排水基準を定める省令を開くと、第六条の二が地の文の1行になり、ほかの条がまとめて行にならないこと。
5. `npm run build` が通ること。告示を読み直したときは `npm run sources:read` のあと `npm run summary` も流すこと。
