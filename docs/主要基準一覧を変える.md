# 主要基準一覧を変える

主要基準一覧は、物質を行に、複数の法令・告示を列にした1枚の表です。トップ画面と `docs/主要基準一覧.md` は同じ組み立て（`src/summary/summary.js`）で作ります。
指定は Markdown 2枚で、どちらにも数値は書きません。プログラムは直しません。

| ファイル | 中身 |
|---|---|
| `src/summary/columns.md` | 列。列名、単位、出典、表 |
| `src/summary/rows.md` | 行。分類ごとの物質と、各列の出典でのその物質の呼び方 |

## 列を足す

`src/summary/columns.md` の「## 列」の表に1行足します。左からこの順で出ます。

| 欄 | 書くこと |
|---|---|
| 列名 | 画面の列の名前 |
| 単位 | セルの値の単位がこれと同じときは数値だけを出す。違う単位はセルに書く |
| 出典 | 法令なら法令ID（API の現行版から取る）。告示なら `sources/notes/` の名前（`sources/read/{名前}.json` から取る）。「、」で複数書くと、左の出典に項目があればそれを使い、無ければ右を見る |
| 表 | 法令のときだけ。抜き出しの表の名前（別表第一、本則など）。「、」で複数書ける。`別表第二=生活環境項目` と書くと、その表の値の頭に語が付く |
| 注記 | その列の基準の適用範囲など。列見出しに「注n」が付き、表の下に出る。空欄でよい |

法令を出典にしたときは、「## 法令名」の表にも1行足すと、表の下の出典欄に法令名と使う表の意味が出ます。

列を足したら、`src/summary/rows.md` の各分類の表にも同じ列名の列を足します（無い列は空欄の扱いです）。

## 列の基準に無い物質を、別の出典で補う

環境基準に無い物質の要監視項目の指針値や、水道水質基準に無い物質の水質管理目標設定項目の目標値のように、
**列の本来の基準ではないが参考に載せたい値**は、次のようにします。

1. その出典を [出典を足す.md](出典を足す.md) の手順で `sources/notes/` に整理し、`npm run sources:read` で読む。
2. `src/summary/columns.md` の「## 補う出典」に1行足す。出典名、頭に付ける語（例: 要監視、目標）、意味。
3. `src/summary/rows.md` のその物質・その列のセルに `出典名: 呼び方` と書く。

補った値は頭に語が付き、画面では色を変え、表の下の「頭に語が付いた値」に意味が出ます。
今は要監視項目（公共用水域・地下水）と水質管理目標設定項目（本体・農薬類）を登録しています。
新しい種類（たとえば水道の要検討項目）も、出典を整理して1行足せば使えます。

## 物質を足す

`src/summary/rows.md` の分類（`## 見出し`）の表に1行足します。分類を増やすときは `## 見出し` と表を1つ足します。

- 「物質名」は画面に出す名前です。
- 各列のセルには、**その列の出典の表に出てくる呼び方**を書きます（条文・告示の表記のまま。全角・半角も合わせる）。
  比べるときは空白、かっこ書き、〈ルビ〉、頭の号番号を無視します（`src/summary/summary.js` の `itemKey`）。
- 空欄は「その出典にこの物質の項目が無い」です。規制が無いという意味ではありません。
- 列の出典と別の出典から取るときは `出典名: 呼び方` と書きます（例: `ダイオキシン類環境基準: 土壌`）。出典名には法令IDも書けます。
- 書いた呼び方が出典に見つからないときは、画面と一覧に赤字で「出典に見つからない」と出ます。呼び方を直してください。

出典での呼び方がわからないときは、その法令を画面で開いて「項目」を見るか、`sources/read/{名前}.json` の `item` を見ます。

## セルの出し方

セルの文字は `src/summary/summary.js` の `cellText` が作ります。

- 「検出されないこと」はそのまま出します。
- 「かつ」「において」「にあっては」「合計」「乗じ」「当分の間」「ただし」を含む基準は条件付きとして ※ を付け、文言を表の下に載せます。
  この言い回しを増やすときは `NOTE_WORDS` に足します。
- 「シス体にあっては…、トランス体にあっては…」のような書き分けは、「シス体 0.004 / トランス体 0.004」のように並べます。
- 同じ項目で条件の違う値が法令に複数あるとき（排水基準のふっ素・ほう素の海域以外／海域）は、「8（海域以外） / 15（海域）」のように並べます。
- 列見出しの単位と違う値は、単位を付けてかっこ書きにします（例: （1000 pg-TEQ/g））。

## 一覧の Markdown を作り直す

```
npm run summary                    docs/主要基準一覧.md に書く
npm run summary -- 別の場所.md      書き出し先を変える
```

Markdown の書き方は `src/summary/markdown.js` で、画面の「ダウンロード」と共通です。表の下の「読み方の注意」は、そこの `READING_NOTES` に1行ずつ書きます。
